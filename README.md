# Kent Ridge Food Web Challenge

An interactive drag-and-drop quiz that teaches participants about the food web at Kent Ridge Park. Players match seven local plants and animals to their correct positions by following feeding and predator relationships.

## Live app

[kent-ridge-food-web.vercel.app](https://kent-ridge-food-web.vercel.app)

## Local development

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```

## Deployment

The project is configured for Vercel through `vercel.json`. Import the repository in Vercel or deploy from the command line with:

```bash
pnpm dlx vercel deploy --prod
```
